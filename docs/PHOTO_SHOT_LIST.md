# AIT website — photo shot list

**19 photographs still needed.** These show the real campus, people and events, so they must be actual photographs — not AI-generated. Everything else on the site is already in place.

> **Current state (13 Oct 2026):** AI concept renders are standing in for all 19 slots so the preview looks complete for review. Each one carries a visible "Concept image" label on the site. They depict fictional buildings, rooms and people and **must not go live** — the label stays until the real photo below replaces it.

Name each file exactly as its **slot id** (e.g. `campus-city.jpg`), put them in one folder and send it over. Sizes below are minimums; larger is fine if the shape matches.

## Before the shoot

- **Permission** — anyone recognisable in a photo must agree to appear on the website (keep a written record). Shots with no people need no consent.
- **Tidy and switched on** — clear desks, no personal belongings, screens on, lights on, blinds open.
- **Time of day** — exteriors in morning or late-afternoon daylight; interiors with natural light where possible.
- **Camera** — a modern phone is fine. Hold it level, shoot landscape (wide) unless noted, and leave space around the subject so we can crop.
- **No branding of other organisations** in frame (posters, logos, uniforms from elsewhere).
